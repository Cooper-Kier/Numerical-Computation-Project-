## NOAA Snowfall Prediction Project  
Welcome to our numerical computation project! This analysis-driven project uses real-world snowfall data from the NOAA API to predict future snowfall at Colorado ski resorts using a combination of numerical methods.

## Technologies

- **Python**: The primary language used for data processing, analysis, and visualization.
- **NOAA API**: Source of historical snowfall data, providing the foundation for our predictive models.
- **Lagrange Interpolation**: Used to estimate snowfall trends by fitting polynomials through known data points.
- **Weighted Historical Averaging**: Applied to give more significance to recent snowfall patterns, improving forecast reliability.
- **Simpson’s Rule**: Employed for numerical integration to estimate cumulative snowfall over a given period.
